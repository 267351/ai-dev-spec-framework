## 七、规范实施指南

### 7.1 新项目启动

1. **选择核心规范**：必须遵守L1核心规范（C01-C07）
2. **选择最佳实践**：根据项目需求选择L2最佳实践（B01-B10）
3. **选择场景规范**：根据项目场景选择L3场景规范（S01-S15）
4. **定制规范**：根据项目特点定制规范

### 7.2 现有项目改进

1. **评估现状**：检查现有项目对规范的遵循情况
2. **识别差距**：识别与规范的差距
3. **制定计划**：制定改进计划
4. **逐步实施**：逐步实施改进

### 7.3 AI辅助开发

1. **加载规范**：将规范加载到AI上下文
2. **执行检查**：AI检查代码是否符合规范
3. **提供建议**：AI提供改进建议
4. **记录偏差**：记录并处理偏差
