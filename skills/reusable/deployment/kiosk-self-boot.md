# Kiosk Self-Boot Deployment

> **Category**: Deployment  
> **Reusable**: ✅ Yes — copy to any on-premise industrial/display deployment  
> **Dependencies**: Bash (Linux) or PowerShell (Windows), browser installed

---

## When to Use

Your application runs on a dedicated machine as a self-service terminal, information kiosk, or industrial workstation:
- No keyboard/mouse interaction expected (or minimal)
- Browser must launch fullscreen automatically on boot
- Multiple monitors with specific window placement
- Crash recovery without human intervention

---

## Key Features

1. **Headless detection** — skip browser launch if no display (WSL, SSH)
2. **Browser priority chain** — Chrome → Chromium → Edge → Firefox
3. **Window geometry persistence** — save/restore window position
4. **Root-user sandbox workaround** — auto `--no-sandbox`
5. **Service readiness check** — wait for Launcher `.ready` file

---

## Implementation (Bash)

```bash
#!/bin/bash
# start-kiosk.sh — generated by deploy.sh

# 1. Headless detection
if [ -z "$DISPLAY" ] && [ -z "$WAYLAND_DISPLAY" ]; then
    echo "Headless environment detected, skipping browser launch"
    LAUNCH_BROWSER=false
fi

# 2. Find browser (priority chain)
find_browser() {
    for cmd in google-chrome-stable google-chrome chromium-browser chromium microsoft-edge firefox; do
        if command -v "$cmd" &>/dev/null; then
            echo "$cmd"
            return
        fi
    done
    echo ""
}
BROWSER=$(find_browser)

# 3. Root-user sandbox workaround
SANDBOX_FLAG=""
if [ "$EUID" -eq 0 ]; then
    case "$BROWSER" in
        *chrome*|*chromium*|*edge*) SANDBOX_FLAG="--no-sandbox" ;;
    esac
fi

# 4. Wait for services
while [ ! -f "./deploy/.ready" ]; do
    sleep 1
done
echo "Services ready"

# 5. Launch browser fullscreen with saved geometry
if [ -f ".browser-state" ]; then
    source .browser-state  # Restore saved position
    $BROWSER $SANDBOX_FLAG --window-position=$WIN_X,$WIN_Y \
             --window-size=$WIN_W,$WIN_H --kiosk "http://localhost:5193" &
else
    $BROWSER $SANDBOX_FLAG --kiosk "http://localhost:5193" &
fi
BROWSER_PID=$!

# 6. Save window geometry on exit (Linux with wmctrl)
save_geometry() {
    if command -v wmctrl &>/dev/null; then
        eval $(wmctrl -lG | grep "localhost" | awk '{print "WIN_X="$3,"WIN_Y="$4,"WIN_W="$5,"WIN_H="$6}')
        echo "WIN_X=$WIN_X; WIN_Y=$WIN_Y; WIN_W=$WIN_W; WIN_H=$WIN_H" > .browser-state
    fi
}
trap save_geometry EXIT

# 7. Interactive menu
echo "Press R to restart, Q to quit"
while true; do
    read -n 1 -t 1 key
    case "$key" in
        r|R) kill $BROWSER_PID; exec "$0" ;;
        q|Q) kill $BROWSER_PID; exit 0 ;;
    esac
done
```

## Multi-Monitor Setup

```bash
# Launch browser on specific monitor
# Monitor 1 (left, 1920x1080): --window-position=0,0
# Monitor 2 (right, 1920x1080): --window-position=1920,0

# Screen A (operations) → left monitor
google-chrome --window-position=0,0 --window-size=1920,1080 --kiosk \
    "http://localhost:5193/operations" &

# Screen B (cameras) → right monitor
google-chrome --window-position=1920,0 --window-size=1920,1080 --kiosk \
    "http://localhost:5193/operations/cameras" &
```
